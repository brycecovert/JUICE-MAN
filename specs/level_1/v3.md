# Level 1 — v3

When Pac-Man dies, the maze shatters into individual blocks that wobble, tumble, and fall off-screen with quirky physics.

- Maze Collapse: On death, every wall block detaches and becomes a free-falling physics object
- Staggered Trigger: Each block receives a random delay (0-400ms) before gravity takes hold, creating a cascading fall effect
- Angular Velocity: Each block spawns with random rotational velocity between -90° and +90° per second (0 = straight up initial kick)
- Wobble Physics: Blocks oscillate rotationally while falling using sine modulation based on their position
- Gravity Fall: Standard gravity acceleration pulls blocks downward with slight horizontal drift based on initial angle
- Rainbow Fade: Blocks retain their current neon color but fade brightness as they fall, leaving colorful trails
- Screen Shake: Brief intense screen shake (200ms) triggers when the collapse begins
- Ghost Freeze: Ghosts stop moving and fade out as blocks begin to fall
- Reset: After all blocks fall off-screen, maze smoothly rebuilds itself from top-to-bottom over 500ms before respawn
