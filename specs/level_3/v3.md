# Level 3 — v3

The dream's stability collapses into a stunning display of recursive fragmentation, turning every ghost-hunt into a shattering of reality.

- **Mirror-Crack Impact**: Eating a ghost causes the screen to visually "fracture" into random triangular shards, each reflecting a slightly different offset of the game state for 100ms.
- **Recursive Ghost Shatter**: The eaten ghost explodes into a recursive fractal of smaller, spinning ghost-silhouettes that spiral outward before dissolving into prismatic dust.
- **Prismatic Afterglow**: The fracture lines leave glowing, neon-colored "cracks" on the screen that slowly fade, creating a temporary web of light over the maze.
